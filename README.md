# 🥗 Calories Predictor AI

Нейронная сеть на базе **TensorFlow/Keras**, предназначенная для прогнозирования калорийности продуктов питания на основе содержания в них белков, жиров и углеводов (БЖУ).

---
## 🚀 Описание проекта
Проект автоматически загружает датасет из Google Drive, выполняет его предобработку, масштабирует данные и обучает полносвязную нейронную сеть для регрессионного анализа.

---
## 🛠 Стек технологий
* **Python 3.x**
* **TensorFlow / Keras** (архитектура модели)
* **Scikit-learn** (предобработка данных: `StandardScaler`, `train_test_split`)
* **Pandas** (анализ и очистка данных)
* **gdown** (загрузка датасетов из облака)
---
## 🧠 Архитектура модели
Модель представляет собой полносвязную нейронную сеть (MLP):
1. **Входной слой:** 3 нейрона (БЖУ).
2. **Скрытые слои:** 32 и 16 нейронов с использованием `BatchNormalization` для стабилизации обучения и `Dropout` (0.2) для предотвращения переобучения.
3. **Функция активации:** ReLU на всех слоях.
4. **Выходной слой:** 1 нейрон (предсказание калорийности).
5. **Оптимизация:** Adam, функция потерь — MSE (Mean Squared Error).

## 📋 Инструкция по запуску

### 1. Клонирование репозитория
```bash
git clone https://github.com/ckfdf935/Calories-Predictor-AI.git
cd Calories-Predictor-AI
```
### 2. Создание и активация виртуального окружения

**Windows:**
```bash
python -m venv .venv
.venv\Scripts\activate
```

**Linux / macOS:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установи зависимости

```bash
pip install -r requirements.txt
```
### 4. Подготовка данных

* **Загрузите свой датасет на Google Drive**
* **Скопируйте ID файла**
* **Откройте `main.py` и вставьте ваш ID в переменную `file_id`** 
```bash
file_id = "ВАШ_ID_ФАЙЛА"
```

### 5. Запуск обучения

```bash
python main.py
```
